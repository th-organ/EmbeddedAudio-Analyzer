# MATLAB-based-audio-signal-acquisition-concatenation-and-spectral-analysis
MATLAB-based audio signal processing platform for STM32 ADC-acquired data, featuring binary DAT file handling, audio concatenation, sample verification, time-domain analysis, FFT-based spectral analysis, and Welch Power Spectral Density (PSD) estimation. Includes captured audio datasets for signal processing, analysis, and experimentation.
I have also attached a fun research paper to understand how the code is applied!
